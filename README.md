# MovieBox

Sistema desenvolvido em React + Vite para organização de tarefas relacionadas a filmes.

## Funcionalidades

- Adicionar tarefas
- Definir categoria
- Definir prioridade
- Marcar tarefa como concluída
- Remover tarefas
- Filtrar tarefas
- Relógio em tempo real
- Salvar tarefas no localStorage

## Como executar

Instale as dependências:

npm install

Execute o projeto:

npm run dev
