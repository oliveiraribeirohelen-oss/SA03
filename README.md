# MovieBox

Sistema desenvolvido em React + Vite para organização de tarefas relacionadas a filmes.

## Funcionalidades

- Adicionar tarefas
- Definir categoria
- Definir prioridade
- Marcar tarefa como concluída
- Remover tarefas
- Filtrar tarefas
- Relógio em tempo real
- Salvar tarefas no navegador
- Recursos de acessibilidade

## Tecnologias

- React
- Vite
- JavaScript
- CSS

## Como executar

npm install

npm run dev
